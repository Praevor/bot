# Praevor

A Discord bot for managing ERLC servers

**Invite:**
https://discord.com/oauth2/authorize?client_id=1299303219406700546

## Features

**Moderation**

- Create moderations
- Get moderations
- Delete moderations

**Server managing**

- Get server info
- Get server players
- Get specific player with their location
- Run a command

## Self-hosting

**It is not suggested to self-host as it is free**

**Steps**

1. Make a .env file and paste the .env.example in it
2. Fill out the values
3. Run it with `docker compose up`

If you did everything correctly then your bot should be online
